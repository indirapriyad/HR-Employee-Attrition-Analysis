# HR Employee Attrition & Salary Analysis

## 📊 Project Overview

This project analyzes employee data to understand employee attrition, salary patterns, job satisfaction, and department-wise employee turnover.

The goal is to identify useful HR insights from employee data using Python and Pandas.

## 🎯 Objectives

* Calculate the total number of employees
* Calculate the employee attrition rate
* Analyze average employee salary
* Identify departments with higher attrition
* Analyze salary differences between departments
* Understand employee satisfaction and attrition patterns

## 🛠️ Tools & Technologies

* Python
* Pandas
* Matplotlib
* Google Colab
* GitHub

## 📁 Dataset

The dataset contains employee information including:

* Employee ID
* Age
* Department
* Salary
* Years at Company
* Job Satisfaction
* Attrition

## 🔍 Analysis Performed

### 1. Employee Attrition

Calculated the number and percentage of employees who left the organization.

### 2. Department-wise Attrition

Analyzed which departments had the highest number of employees leaving.

### 3. Salary Analysis

Calculated and compared the average salary across different departments.

### 4. Employee Satisfaction

Examined job satisfaction levels and their relationship with employee attrition.

## 📈 Key Findings

Based on the sample dataset:

* Total employees analyzed: 10
* Employees who left: 5
* Attrition rate: 50%
* Average salary: ₹43,000
* HR and Sales showed employee attrition in the sample dataset.

> Note: This is a small sample dataset created for learning and portfolio development. The findings should not be treated as representative of a real organization.
